01

注册与登录

先进入管理员提供的 New API 地址，再进入控制台查看线路。

  1. 打开管理员提供的 New API 地址：https://aiyunrouter.com。
  2. 使用账号密码注册，或使用管理员启用的 GitHub、Discord、OIDC、Telegram 等方式登录。
  3. 登录后进入控制台；若平台关闭注册，请联系管理员创建账号。
  4. 在概览页面查看 API 调用地址。大陆用户使用大陆环境地址，海外网络或全局 VPN 使用 CF 线路。
i首次进入控制台时，先确认自己使用的网络线路，再把对应 Base URL 写入客户端。
02

创建 API Key

API Key 是调用接口的凭证，每个 Key 都可以独立设置权限和额度。

  1. 左侧进入“API 秘钥”，或访问 /console/token。
  2. 点击“创建 API 秘钥”，填写令牌名称，例如生产环境、测试项目、本地开发。
  3. 按需设置过期时间、分组、剩余配额、模型限制和 IP 白名单。
  4. 点击“保存更改”，立即复制完整令牌 Key。
配置项说明
过期时间到期后自动失效；留空或选择永不过期表示长期有效。
分组指定 Key 可以使用的模型渠道分组，调用模型时按对应分组倍率扣费。
额度设置可以限制 Key 的最大消耗额度，也可以设置无限配额。
模型限制只允许调用指定模型；留空表示允许所有模型。
IP 白名单只允许指定来源 IP 使用该 Key。
!完整令牌只会在创建时显示。Key 以 sk- 开头，泄露后别人可能消耗你的额度。
03

接入客户端

根据使用习惯选择 CC-Switch、直接配置 Codex，或在 Workbuddy / TRAE 中添加自定义模型。

  1. 下载 CC-Switch，选择对应的模型分组。
  2. 点击右上角“+”，填入接口地址与 API Key。
  3. 保存并启用配置，然后打开或重启 Codex。

06
API 调用
以下示例使用 OpenAI 兼容格式。把域名、模型和 Key 替换成管理员实际配置即可。

        
获取模型列表
GET /v1/models
curl "https://cnapi.aiyunrouter.com/v1/models" \
  -H "Authorization: Bearer sk-你的令牌"
GET /v1beta/models
curl "https://cnapi.aiyunrouter.com/v1beta/models" \
  -H "Authorization: Bearer sk-你的令牌"

        
调用 Chat Completions
这是最常见的 OpenAI 兼容接口。
curl -X POST "https://你的域名/v1/chat/completions" \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "请用一句话介绍 New API"}],
    "stream": false
  }'
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的令牌",
    base_url="https://你的域名/v1"
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "请用一句话介绍 New API"}],
)

print(resp.choices[0].message.content)

        
调用 Responses 接口
POST /v1/responses
curl -X POST "https://你的域名/v1/responses" \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "input": "写一个三点式项目总结"
  }'

        
Claude Messages 与 Gemini 格式
如果管理员已配置 Claude 或可转换渠道，可以使用 Claude Messages 兼容接口；具体路径以平台接口文档或管理员说明为准。调用时仍使用 New API 令牌作为认证凭证。
如果管理员已配置 Gemini 渠道，可以使用 Gemini 兼容接口，例如 /v1beta/models。调用时仍使用 New API 令牌。

08
常见问题
遇到接入问题时，先从线路、Key 和路径三个方面排查。

        
为什么调用地址后面要加 /v1？
Codex 等 OpenAI 兼容客户端通常将 Base URL 指向版本路径。直接配置 Codex 时，请在 config.toml 中填写带 /v1 的地址。

        
大陆和海外 / CF 线路怎么选？
大陆网络环境使用大陆环境地址；海外网络或打开全局 VPN 时使用 CF 线路。以管理员提供的实际地址为准。

        
Key 泄露了怎么办？
立即回到 API 秘钥页面禁用或编辑该 Key，并创建一个新的 Key。建议按环境拆分令牌，并设置额度和 IP 白名单。
